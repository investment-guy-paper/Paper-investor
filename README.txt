PAPER INVESTOR — iPhone install
================================

Upload ALL of these files together, keeping them in the same folder:

  index.html
  manifest.webmanifest
  sw.js
  icon-180.png
  icon-192.png
  icon-512.png
  icon-maskable-512.png

Do not rename anything. Do not put them in a subfolder.

FASTEST HOSTING (2 minutes, on your PC)
---------------------------------------
1. Go to app.netlify.com/drop
2. Drag the whole extracted folder onto the page
3. You get a URL like https://something-random.netlify.app
4. Open that URL on your iPhone IN SAFARI (not Chrome)
5. Tap the Share button, then "Add to Home Screen", then "Add"

GITHUB PAGES (permanent, free)
------------------------------
1. github.com -> New repository -> name it paper-investor -> Public -> Create
2. "uploading an existing file" -> drag all 7 files -> Commit changes
3. Settings -> Pages -> Source: "Deploy from a branch" -> main / (root) -> Save
4. Wait ~1 minute, then open https://YOURNAME.github.io/paper-investor/
5. On iPhone, open that URL in Safari -> Share -> Add to Home Screen

IMPORTANT
---------
- It MUST be Safari on iPhone. Chrome/Firefox on iOS cannot install to home screen.
- After installing, open it from the HOME SCREEN ICON, not from Safari.
  Progress is stored separately for each, and only the installed app keeps it reliably.
- It works with no internet after the first launch.
- Back up your progress: Progress tab -> Export save file.
